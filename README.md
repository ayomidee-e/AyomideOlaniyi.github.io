# Portfolio Website

My personal portfolio site, hosted on GitHub Pages. 

It's a single-page responsive layout customized from the HTML5 UP "Miniport" template to showcase my engineering projects and experience.

## Tech Stack

* HTML5 & CSS3
* JavaScript / jQuery
* Miniport Template (HTML5 UP)
* Hosted on GitHub Pages
